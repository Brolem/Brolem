### 最近在做

目前在做算电协同滚动调度研究：当计算任务和风光出力都不确定时，怎样安排任务、储能和购电？我正在比较不同调度策略，观察降低购电成本与让柔性任务更早完成之间的取舍，并检验这些策略在连续多天运行中的表现。

### 从预测到决策

也在学习需求预测与库存补货。一个简单但重要的例子：如果周五下单、周六到货，订货依据应对齐**周六的需求**；只看周五销量，可能漏掉周末需求上升。缺货时销量也不等于真实需求，需要结合库存状态理解数据。
