### 当前研究

在计算任务与风光出力都有不确定性的条件下，研究任务调度、储能与购电的协同。以 48 小时计划、首 24 小时执行的滚动框架，比较**实际购电费用、柔性任务完成延迟与跨日可行性**。

已完成一组 2024 年连续 504 小时回放：七档权衡参数中，四档完成全程，三档在后续滚动日出现已证明的不可行；双侧与单侧场景的 2×2 对照也已完成。结果来自特定合成配对数据和已接触的评价窗口，不能解释为盲测、通用降本率或生产收益。
